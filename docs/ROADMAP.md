# Production roadmap

## 1. Технический фундамент

- [x] Модульная структура исходников.
- [x] Конфигурации уровней отдельно от игрового UI.
- [x] Автоматические тесты игровой сетки.
- [x] Production-сборка Vite.
- [x] Автоматический ZIP для Яндекс Игр.
- [x] GitHub Actions для проверки каждого изменения.

## 2. Уровни и инструменты баланса

- [x] Версионируемая схема уровня.
- [x] Карта уровней и выбор главы.
- [x] Debug-панель выбора и мгновенного завершения уровня.
- [ ] Проверка существования решения.
- [ ] Симулятор сложности и статистика возможных цепочек.
- [x] Первые 15 авторских уровней.

## 3. Профиль и прогресс

- [x] Версионируемое сохранение профиля.
- [x] Уровень, звёзды, монеты и рекорд.
- [ ] Инвентарь бустеров.
- [ ] Достижения и ежедневные задания.
- [ ] Браузерное и облачное хранилища через один интерфейс.

## 4. Экономика и контент

- [ ] Источники и расходы мягкой валюты.
- [ ] Бустеры: дополнительные ходы, перемешивание, радужный фрукт и удар по ящику.
- [ ] 30–40 сбалансированных уровней.
- [ ] Обучение и постепенное введение механик.
- [x] События аналитики для воронки и баланса.

## 5. Яндекс Игры и монетизация

- [ ] SDK, Game Ready и разметка геймплея.
- [ ] Облачные сохранения и лидерборд.
- [ ] Fullscreen и rewarded-реклама в логических паузах.
- [ ] Каталог покупок и обработка незавершённых транзакций.
- [ ] Пауза игры, звука и таймеров во время рекламы.

## 6. Релиз

- [ ] Тестирование на desktop и mobile.
- [ ] Soft launch и настройка баланса по метрикам.
- [ ] Иконка, обложка, скриншоты, описание и инструкция.
- [ ] Проверка через debug-панель Яндекс Игр.
- [ ] Модерация и публикация.
