# Фрукты 10

Небольшая HTML5-игра: выбирайте фрукты так, чтобы сумма чисел на них равнялась 10.

## Запуск локально

Откройте `index.html` в браузере. Сборка и сервер не требуются.

## Файлы

- `index.html` — разметка игры;
- `styles.css` — оформление и анимации;
- `game.js` — игровая логика.

## Публикация

Проект совместим с GitHub Pages и любым статическим хостингом.
