# Фрукты 10+

HTML5-игра про светящиеся цепочки фруктов, меняющиеся целевые суммы, бомбы и разрушаемые препятствия.

В игре есть кампания из 100 уровней и десяти глав, карта прогресса, лёд, ящики, бомбы, обучение, четыре бустера, монеты и локальное сохранение профиля. Расчётная продолжительность кампании — около 6,5 часа без учёта повторных попыток.

## Разработка

Требуются Node.js 22+ и pnpm.

```bash
pnpm install
pnpm dev
```

Vite запустит локальный сервер и будет обновлять игру после изменений.

## Проверки и сборка

```bash
pnpm check
pnpm test
pnpm balance:audit
pnpm build
```

Production-сборка создаётся в `dist/`.

Полный релизный pipeline для Яндекс Игр:

```bash
pnpm release:yandex
```

Команда проверяет синтаксис, запускает тесты, собирает production-версию и создаёт `artifacts/fruit-10-plus-yandex.zip`. Внутри архива `index.html` находится в корне, как требует Яндекс Игры.

## Структура

- `src/config/levels.js` — конфигурации уровней;
- `src/config/products.js` — каталог бустеров и будущих покупок;
- `src/core/grid.js` — чистая игровая математика поля;
- `src/core/profile.js` — версия и обновление профиля игрока;
- `src/core/progression.js` — звёзды и прогресс заданий;
- `src/core/store.js` — кошелёк, инвентарь и безопасное начисление транзакций;
- `src/core/analytics.js` — платформенно-независимые игровые события;
- `src/platforms/browser.js` — браузерные сохранения и платформенный интерфейс;
- `src/platforms/mock-store.js` — тестовый магазин без списания денег;
- `src/game.js` — игровой процесс и UI;
- `test/` — автоматические тесты;
- `scripts/package-yandex.mjs` — создание ZIP для Яндекс Игр;
- `scripts/audit-campaign.mjs` — валидация контента и расчёт длительности;
- `.github/workflows/ci.yml` — автоматическая проверка каждого изменения.

План развития продукта хранится в [`docs/ROADMAP.md`](docs/ROADMAP.md), а продуктовые метрики, экономика и требования площадки — в [`docs/COMMERCIALIZATION.md`](docs/COMMERCIALIZATION.md).

Для панели балансировки откройте игру с параметром `?debug=1`. Панель позволяет выбирать и мгновенно завершать уровни, а события аналитики выводятся в консоль и отправляются через событие `fruit10:analytics`.
